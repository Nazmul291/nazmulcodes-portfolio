# Assets Directory (`public/assets/`)

You can place your images, photos, lifestyle pictures, and project screenshots in this folder. Any file placed here is directly served by Remix / Vite at `/assets/...`.

## Directory Structure:
- `public/assets/images/profile/` — Your avatar, headshots, and personal profile pictures (e.g. `/assets/images/profile/nazmul.jpg`).
- `public/assets/images/lifestyle/` — Lifestyle, workspace, desk setup, and conference photos (e.g. `/assets/images/lifestyle/workspace.jpg`).
- `public/assets/images/projects/` — Screenshots and mockups of client stores and Shopify apps.

## How to use in React / Remix:
```tsx
<img src="/assets/images/profile/nazmul.jpg" alt="Nazmul Hawlader" />
```
